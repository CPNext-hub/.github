# CP Next

> **Code. Create. Connect.**

CP Next คือชมรมภายใต้ **CM HUB** สำหรับนักศึกษาที่สนใจการเขียนโค้ด เทคโนโลยี และการสร้างสิ่งใหม่ ๆ ร่วมกัน

เราเชื่อว่าไอเดียที่ดีไม่ควรหยุดอยู่แค่ในหัว ไม่ว่าคุณจะเพิ่งเริ่มเขียนโค้ด มีโปรเจกต์ที่อยากทำ หรือกำลังมองหาเพื่อนร่วมทีม ที่นี่คือพื้นที่สำหรับเรียนรู้ แลกเปลี่ยน และลงมือสร้างให้เกิดขึ้นจริง

## ที่ CP Next เราทำอะไรบ้าง?

- เรียนรู้และฝึกเขียนโค้ดไปด้วยกัน
- สร้างโปรเจกต์ เช่น เว็บไซต์ แอปพลิเคชัน เกม และเครื่องมือที่ช่วยแก้ปัญหา
- แลกเปลี่ยนความรู้ ไอเดีย และประสบการณ์จากเพื่อน ๆ
- หาเพื่อนร่วมทีมสำหรับทำโปรเจกต์หรือเข้าร่วมการแข่งขัน
- เปิดพื้นที่ให้ทุกคนได้ทดลอง สร้าง และพัฒนาตัวเอง

## ใครเข้าร่วมได้บ้าง?

ทุกคนที่สนใจครับ — ไม่ต้องเก่งตั้งแต่วันแรก ขอเพียงมีความอยากรู้ อยากลอง หรืออยากสร้างบางอย่างด้วยโค้ด แล้วมาเติบโตไปด้วยกัน
